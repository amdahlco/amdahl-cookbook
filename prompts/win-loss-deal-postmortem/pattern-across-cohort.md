# Pattern across cohort

**What this does**: Finds the common threads across a group of deals — all the losses last quarter, all the wins in a segment, all the no-decisions in Q3.

**When to use it**: You sense a pattern but you don't have the time (or the patience) to read 40 deal notes by hand.

## Paste this into Claude

```
Look at every {closed-lost / closed-won / no-decision} deal in {segment or time window — e.g. "Q3 mid-market" or "the last 6 months in fintech"}. What patterns show up? Group by theme — common objections, common competitors, common deal-stage where things broke, common buyer roles that pushed back. For each theme, give me the count and 2-3 verbatim quotes. End with the single biggest pattern and what it suggests about our motion.
```

## What you'll see back

- 4-6 themes, each with a count and quotes.
- Patterns by deal stage (where things broke).
- Patterns by buyer role (who pushed back).
- A single "biggest pattern" summary at the end.

## Variations

- Tight: `Just the top 3 patterns, with 1 quote each.`
- By rep: `Group by which rep owned the deal — are we seeing rep-specific patterns?`
- Add: `Recommend the single change we should make to our motion based on this.`

## Tips

- Bigger cohorts surface stronger patterns. Aim for 10+ deals minimum.
- If the segment is too broad, the patterns get mushy — narrow by segment or stage.
- For one-deal depth, use [why we lost this deal](why-we-lost-this-deal.md).
