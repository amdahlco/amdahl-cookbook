# Why we lost this deal

**What this does**: The honest postmortem on one closed-lost deal — based on what was actually said on calls, not what got selected from the CRM dropdown.

**When to use it**: A deal you cared about just closed-lost. Before the memory fades and the rationalizations harden, you want the real story.

## Paste this into Claude

```
We just closed-lost the {company name} deal. Walk me through what actually happened. Pull the timeline — every meaningful touch, what was said, where sentiment shifted. Tell me: where did the deal turn? Was there a moment we lost it? What did they say (verbatim) about why they went a different direction? Which objections did we fail to handle? Was a competitor in there, and if so, when did they show up? End with the 3 things we'd do differently if we ran this deal again.
```

## What you'll see back

- A short narrative timeline with the turning points marked.
- Verbatim "why we lost" quotes — usually different from the CRM reason.
- Unresolved objections, ranked by how much they likely mattered.
- Competitive context if any.
- 3 do-overs for next time.

## Variations

- Quick version: `Keep it to 5 bullets — I have 5 minutes.`
- Coaching angle: `Frame the do-overs as coaching notes for the rep.`
- Add: `Compare this to the last 3 deals we lost in the same segment — same pattern?`

## Tips

- The CRM-dropdown reason is almost never the real reason. Trust the call quotes.
- If a competitor showed up late, that usually means *something we did* opened the door — ask Claude what.
- For multi-deal patterns, use [pattern across cohort](pattern-across-cohort.md).
