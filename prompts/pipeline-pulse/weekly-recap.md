# Weekly recap

**What this does**: A Monday-morning summary of what moved in the pipeline last week, what stalled, and what to watch this week.

**When to use it**: Every Monday, before the standup. Or every Friday, before you log off.

## Paste this into Claude

```
Recap last week's pipeline activity. Cover: which deals moved forward (and why), which deals slipped (and why), which new deals entered the pipeline, which deals went quiet, and any sentiment changes worth knowing about. End with 3 things to watch this week — specific deals, specific risks, specific next steps. Keep it to 1 page.
```

## What you'll see back

- Movement: what advanced, what slipped, what's new.
- Stalls: deals that went quiet, with the last meaningful touch.
- Sentiment shifts on named deals.
- A "watch this week" list — 3 items, specific.

## Variations

- Team view: `Group by rep.`
- Big deals only: `Only deals over $100K ACV.`
- Add: `End with one question I should ask in the team standup.`

## Tips

- Run it at the same time every week — patterns only show up when the cadence is regular.
- If a deal slipped *and* sentiment changed in the same week, that's the one to chase first.
- Pair with [deals at risk](deals-at-risk.md) and [stalled pipeline triage](stalled-pipeline-triage.md) for deeper cuts.
