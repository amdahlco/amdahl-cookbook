# Audit our positioning

**What this does**: Compares a piece of your own copy — homepage hero, one-pager, deck slide — to how customers actually describe you on calls, and flags the gaps.

**When to use it**: You're rewriting the homepage, refreshing a category narrative, or just got the sinking feeling that the way you talk about yourselves doesn't match how customers talk about you.

## Paste this into Claude

```
Here's a piece of our positioning:

"""
{paste the copy here — hero, one-pager, deck slide, whatever}
"""

Compare it to how our actual customers describe us on calls. Where does it match? Where does it diverge? Where are we using internal jargon that buyers never use? Where are buyers using language that we never use? End with 3 specific rewrites that pull language directly from customer quotes, and tell me which quote each rewrite is grounded in.
```

## What you'll see back

- A match/mismatch readout, line by line if the copy is short.
- A "jargon we use that buyers don't" list.
- A "language buyers use that we don't" list — this is usually the gold.
- 3 grounded rewrites, each tied to a real customer quote.

## Variations

- Segment-specific: `Only compare to how mid-market buyers describe us.`
- Role-specific: `Only how technical buyers describe us.`
- Add: `Score each section out of 10 for how grounded it is.`

## Tips

- Paste the copy in triple-quotes so Claude treats it as input, not instruction.
- The "language buyers use that we don't" section is where new headlines live.
- Run this on competitor copy too — same prompt, paste their hero, see how they'd score against *your* customers' voice.
