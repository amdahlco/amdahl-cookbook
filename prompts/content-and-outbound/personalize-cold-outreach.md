# Personalize cold outreach

**What this does**: Writes a non-generic opener for each prospect on a list — grounded in something real about *them*, not a Mad-Libs template.

**When to use it**: You're about to send cold outreach and "Hi {first_name}, I noticed you're at {company}" makes you wince.

## Paste this into Claude

```
For each prospect on this list, write a 2-sentence cold-outreach opener that I'd actually send. Ground it in something specific to them — recent funding, a public post, a hire, a product launch, something one of their executives said publicly. No generic "I see you're at {company}" openers. If you can't find a specific hook for someone, say so and skip them.

List:
{paste prospect list — name, role, company, domain — one per line}
```

## What you'll see back

- One 2-sentence opener per prospect, each tied to a specific hook.
- A "couldn't find a hook" call-out for anyone where the signal was thin.
- Often: 2-3 surprising hooks you wouldn't have spotted yourself.

## Variations

- LinkedIn DM tone: `Make these LinkedIn DMs, not emails — softer, no signature.`
- One-to-many: `Write a single email that works for everyone on the list — and tell me why each opener wouldn't work better.`
- Add: `Also draft a 1-sentence subject line per email.`

## Tips

- 10-20 prospects per run is the sweet spot. Bigger lists get sloppy.
- "Skip if no hook" is the rule that keeps quality high. Don't force it.
- Pair with [outbound targeting by signal](outbound-targeting-by-signal.md) to build the list first.
